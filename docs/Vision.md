# Vision

Saqr-JO is an AI-powered Windows Security Operations Assistant designed to help security analysts investigate Windows security events collected from Sysmon. Instead of overwhelming analysts with raw logs, Saqr transforms security events into meaningful incidents by extracting evidence, mapping attacker behavior to the MITRE ATT&CK framework, calculating risk scores, and generating clear incident summaries that support faster and more accurate investigations.

---

# Mission

Our mission is to simplify Windows threat investigations by combining Sysmon event analysis, evidence extraction, MITRE ATT&CK mapping, intelligent risk scoring, and AI-assisted incident reporting into one security platform that empowers analysts without replacing their decisions.

---

# Core Features

- Collect Windows security events from Sysmon.
- Extract forensic evidence from security events.
- Detect suspicious activities using detection rules.
- Map attacks to the MITRE ATT&CK Framework.
- Calculate dynamic risk scores.
- Generate clear incident summaries.
- Store incidents for future investigation.
- Provide an interactive SOC dashboard.
- Support future AI-powered investigation assistance.

# Long-Term Vision

Saqr-JO aims to become a complete Windows Security Platform capable of collecting endpoint telemetry, correlating security events, visualizing incidents through an interactive dashboard, and assisting analysts with AI-driven investigations while keeping humans in full control of every security decision.

---

# Project Philosophy

Saqr-JO is built around one principle:

> **Assist the analyst, not replace the analyst.**

The platform is designed to reduce investigation time, improve incident understanding, and provide explainable security insights that analysts can trust.
